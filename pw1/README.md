# Описание файлов
## `main.cpp`
> Основной файл, в котором расположена реализация генетического алгоритма
## `result.csv`
> Файл с результатами работы генетического алгоритма, в котором расположены комбинации этапов генетического процесса и их score (математическое ожидание и среднеквадратичное отклонение)
## `research.ipynb`
> Файл формата Jupyter Notebook для обработки полученных данных из файла `result.csv`. Проведено сравнение каждого варианта на каждом генетическом этапе
## `research.html`
> Представление проведённого исследования в формате html с динамическими графиками
